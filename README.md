## 关于 DataMind

DataMind 是一个专注于数据分析和可视化的AI平台，它能够帮助用户快速生成数据报告、图表和交互式仪表板。通过简单的自然语言提示，用户可以获得专业质量的数据洞察和可视化效果。

## 技术栈

- 前端: HTML5, CSS3, JavaScript, Bootstrap
- 数据可视化: D3.js, ECharts, Plotly
- 部署: GitHub Pages
